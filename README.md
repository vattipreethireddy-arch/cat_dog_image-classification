# cat_dog_image-classification
Cat vs Dog Image Classification

Project Overview:
This project uses Machine Learning to classify images into two categories: cats and dogs using Python and Support Vector Machine (SVM).

Objectives:
- Load and process cat and dog images.
- Train a machine learning model.
- Predict whether an image contains a cat or a dog.
- Evaluate model performance using accuracy.

Technologies Used:
- Python
- NumPy
- OpenCV
- Scikit-learn
- Matplotlib

Model:
Support Vector Machine (SVM)

Results:
The model achieved an accuracy of 53.85% on the current evaluation.

Future Improvements:
- Increase the dataset size.
- Improve image preprocessing.
- Tune model parameters to improve accuracy.
